Eesmärk

Veebirakendus kasutajakontode haldamiseks (CRUD): registreeritud kasutajate nimekirja vaatamine, uute lisamine ning olemasolevate andmete muutmine ja kustutamine.

Tehnoloogiapinu

Keel & Raamistik: Java 17, Spring Boot

Kasutajaliides: Thymeleaf, Bootstrap 4 (WebJars)

Andmebaas & Projektihaldus: MySQL, Maven

Käivitamine

Andmebaasi seadistus: Loo MySQL-is andmebaas mywebappdb ning veendu, et failis application.properties on õige kasutajanimi ja parool.

Käivitamine:

IntelliJ-s läbi MyWebAppApplication.java faili

Võimalusena terminalis käsk: ./mvnw spring-boot:run

Kasutamine: Ava brauseris `
